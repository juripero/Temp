Local changes in version 0.4.1 add structured HIP errors, explicit device
selection, and IPC export diagnostics. The uncached allocation flags and
peer GPU protocol are unchanged.

The FlyDSL WMMA and compiler interfaces follow the pinned release's examples.
The new peer protocol and integration are experimental and require hardware
qualification as described in README.md.

Version 0.4.2 adds an explicit plain-hipMalloc allocator option and allocator
agreement checks. The peer GPU protocol remains unchanged and requires
separate qualification when using the new memory type.

Version 0.4.3 adds a separate FFN-output peer reduction phase, deferred FFN
layer scaling, and matching host/compiler/test support. It retains the same
HIP allocator options and requires hardware qualification for the new phase.

Version 0.4.4 adds opt-in scalar-64-bit LL publication/polling for both peer
reductions, wrap scrubbing with a reserved invalid tag, and a GPU bit-pattern
probe. Uses FlyDSL/LLVM atomic load/store APIs; no RCCL/NCCL source is copied.
